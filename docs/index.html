Invite Code System

Wie funktionieren Invite Codes?

Das Invite Code System ermöglicht es Projektbesitzern, einzigartige Codes zu erstellen, mit denen andere Benutzer einfach Projekten beitreten können.

Code-Format

  • 6-stellige alphanumerische Codes (A-Z, 0-9)
  • Beispiele: DN9N7T, ABC123, XYZ789
  • Case-insensitive (Groß-/Kleinschreibung egal)

Funktionen

  • Code erstellen: Projekt-Owner können beliebig viele Codes generieren
  • Code teilen: Codes können per E-Mail, Chat oder Link geteilt werden
  • Code nutzen: Benutzer geben den Code ein und treten automatisch dem Projekt bei
  • Code verwalten: Codes können deaktiviert oder gelöscht werden

Nutzungslimits

  • Basic Plan: 2 aktive Codes pro Projekt
  • Pro Plan: 5 aktive Codes pro Projekt
  • Enterprise Plan: Unbegrenzte Codes

Verwendung

  1. Beim Erstellen eines Projekts einen Code generieren
  2. Code mit Team-Mitgliedern teilen
  3. Team-Mitglieder besuchen /projects/join oder /projects/join/CODE
  4. Automatisches Beitreten zum Projekt
URL-Beispiele:
https://yourapp.com/projects/join/DN9N7T
https://yourapp.com/projects/join (mit Code-Eingabe)

API Referenz

POST /projects/create

Erstellt ein neues Projekt mit optionalem Invite Code.

{
  "project_name": "Mein Projekt",
  "description": "Projektbeschreibung",
  "category": "Web Development",
  "template": "ecommerce",
  "privacy": "private",
  "invite_code": "DN9N7T"
}

GET /projects/join/:code

Tritt einem Projekt mit einem Invite Code bei.

GET /projects/join/DN9N7T
